# 项目架构说明：基于深度卡尔曼滤波 (DKF) 的时空序列预测系统

## 1. 项目背景与核心目标
本项目旨在为深度学习课程构建一个基于**深度卡尔曼滤波（Deep Kalman Filters, DKF）**的时空序列预测模型。
区别于传统的确定性黑盒预测（如标准的 ConvLSTM/Seq2Seq），本项目从控制理论和系统辨识的视角出发，将经典的状态空间方程与变分推断（Variational Inference）结合。模型通过无监督方式学习动态系统的隐状态（Latent State）演变动力学，并以此进行未来帧的自回归预测。

**验证策略（两阶段）**：
1. **第一阶段（先行验证）**：在 **Moving MNIST** 数据集上验证 DKF 框架对简单运动模式的预测能力。
2. **第二阶段（目标应用）**：若时间允许且第一阶段效果良好，将模型迁移至真实大气数据（WeatherBench），进行降水预测。

**技术栈要求**：PyTorch (核心框架), torchvision (数据读取), NumPy。

---

## 2. 数据流水线 (Data Pipeline)

### 2.1 第一阶段：Moving MNIST（先行验证）
* **数据集**：`torchvision.datasets.MovingMNIST` 或自定义生成脚本。
* **观测张量 $X_t$ 构成 (Channels = 1, 空间维度 $64 \times 64$)**：
  * 单通道灰度图像，包含 1~3 个运动中的手写数字。
* **预处理策略 (`dataset.py`)**：
  * 滑动窗口切片：划分历史观测窗口 $T_{past}$ 和未来预测窗口 $T_{future}$。
  * 归一化：将像素值从 $[0, 255]$ 线性缩放至 $[0, 1]$ 或 $[-1, 1]$。
* **验证目标**：
  * 模型能否准确捕捉数字的**运动轨迹**（如匀速直线、反弹）。
  * 预测帧是否保持数字的**形状锐度**，而非模糊一团。
  * 隐状态 $Z_t$ 是否编码了有效的运动信息（如位置、速度）。

### 2.2 第二阶段：WeatherBench（目标应用）
* **数据集**：WeatherBench (5.625° 或 2.8125° 低分辨率版本)
* **观测张量 $X_t$ 构成 (Channels = 4, 空间维度 $H \times W$)**：
  1. `2m_temperature` (2米温度)
  2. `10m_u_component_of_wind` (10米U向风速)
  3. `10m_v_component_of_wind` (10米V向风速)
  4. `total_precipitation` (总降水量 - **核心预测目标**)
* **预处理策略 (`dataset.py`)**：
  * 滑动窗口切片：划分历史观测窗口 $T_{past}$ 和未来预测窗口 $T_{future}$。
  * 归一化：风速和温度使用 Z-score 标准化；降水数据由于极度稀疏和长尾特性，必须使用 $\log(1 + x)$ 变换以稳定梯度反向传播。

## 3. 数学建模与网络架构 (`modules.py`)
系统遵循隐马尔可夫结构，包含推断网络（观测器）与生成网络（动力学+测量矩阵）。为保留气象数据的空间拓扑结构，所有核心序列模块均需使用 **ConvLSTM** 或 **ConvGRU**。

### 3.1 识别网络 / 后验推断 (Recognition Network, $q_\phi$)
在训练阶段充当“平滑器/滤波器”，从真实观测序列中提取纯净的隐状态轨迹，引导生成网络学习。
* **架构选择**：采用严格因果的 **q-RNN** 结构，推断 $q(z_t | x_1, \dots, x_t)$。
* **输入**：当前时刻降维特征 $e_t$ (由独立 CNN 编码器提取自 $X_t$) 与上一时刻隐状态 $Z_{t-1}$。
* **输出**：当前后验高斯分布的均值 $\mu_{qt}$ 和对数方差 $\log\Sigma_{qt}$。
* **重参数化采样**：实现可导采样函数 $\hat{Z}_t = \mu_{qt} + \epsilon \odot \sqrt{\exp(\log\Sigma_{qt})}$，其中 $\epsilon \sim \mathcal{N}(0, I)$。

### 3.2 生成模型 / 动力学与观测 (Generative Model, $p_\theta$)
模型的核心动力学引擎，负责系统演变与变量重构。
* **A. 状态转移网络 (Prior / Transition, $p_\theta(z_t | z_{t-1})$)**
  * **作用**：基于 $t-1$ 时刻的隐状态自回归推演 $t$ 时刻的先验分布。
  * **输出**：先验均值 $\mu_{pt}$ 和对数方差 $\log\Sigma_{pt}$。
  * **物理先验接口（第二阶段）**：该模块的卷积核设计可结合大气物理学中的风场辐合辐散机制。可以将特定的大气动力学约束作为正则化项或通道注意力机制引入，引导网络学习符合流体力学的演变规律。
* **B. 观测解码网络 (Emission, $p_\theta(X_t | Z_t)$)**
  * **作用**：将高维隐状态还原为 2D 图像网格（观测矩阵映射）。
  * **架构**：堆叠 `ConvTranspose2d` 进行空间上采样。
  * **第一阶段 (Moving MNIST)**：单通道输出，使用 `Sigmoid` 激活将像素值约束在 $[0, 1]$。
  * **第二阶段 (WeatherBench)**：多通道输出，前三个通道（温、风）使用线性激活，第四个降水通道必须使用 `Softplus` 或 `ReLU` 确保输出非负。

## 4. 变分下界损失函数 (`loss.py`)
优化目标为最大化变分下界（ELBO），在代码中体现为最小化以下两项之和：
1. **重构误差 (Reconstruction Loss)**：
   * 计算网络解码出的 $\hat{X}_t$ 与真实数据 $X_t$ 之间的 MSE。
   * **第一阶段 (Moving MNIST)**：直接使用 MSE 或 BCE，关注图像整体重建质量。
   * **第二阶段 (WeatherBench)**：可针对强降水像素点引入动态权重以缓解数据不平衡。
2. **KL 散度 (KL Divergence)**：
   * 计算后验推断分布 $\mathcal{N}(\mu_{qt}, \Sigma_{qt})$ 与先验转移分布 $\mathcal{N}(\mu_{pt}, \Sigma_{pt})$ 之间的散度。
   * **严格约束**：严禁使用蒙特卡洛采样计算！必须使用两个对角高斯分布之间的闭式解析解公式（Closed-form analytical solution）进行纯张量代数运算。

## 5. 运行模式与执行流 (`model.py`)
`DeepKalmanFilter` 主类的 `forward` 函数必须实现两种截然不同的控制流（通过 `mode` 参数或 `self.training` 标志区分）：
* **训练流 (Filtering & Alignment)**：开启推断网络 $q_\phi$。每一时间步利用真实观测提取后验状态 $\hat{Z}_t$，同时运行转移网络 $p_\theta$ 获取先验分布。收集全序列的重构误差与 KL 散度进行反向传播。
* **预测流 (Autoregressive Forecasting)**：在输入前 $T_{past}$ 个观测完成初始状态估计后，进入滚动预测模式。在每个时间步，若真实观测 $X_t$ 可获取，则先利用推断网络 $q_\phi$ 校准隐状态 $Z_t$；随后仅利用转移网络 $p_\theta$ 向前推演下一步 $Z_{t+1}$，并解码为预测帧。此过程自回归向前推进 $T_{future}$ 步。
  * **第一阶段 (Moving MNIST)**：逐帧预测数字的运动轨迹。
  * **第二阶段 (WeatherBench)**：逐帧解码为未来的降水预测图。
